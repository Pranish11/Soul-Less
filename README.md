# Soul-less
A game I made to learn sfml and c++, some of the code is done by ai in this projet mostly the savemanager one 

## Installation
If You want to add your own things here ,
1. Make sure you have a C++17 compiler or higher.
2. Install SFML (version 3.0 or higher). For this project 3.0.2 was used
3. Clone this repository:
   git clone https://github.com/Pranish11/Soul-Less
4. IDE Used - Visual Studio


## Controls
Player movement : W A S D
- To open up phone : P
- To open inventory : E
- To pause : esc


## Gameplay

The gameplay is kinda shitty but here:
- After you buy anything from the Shop (App from the phone) it will appear in the inventory.
- In the inventory click the item , if white box appears which means the item is selected.
- To place the item down, after selecting the item press E again to close the inventory and click anywhere in the floor.

- To Gamble Click the app with $ sign, then each time you want to bet press play first then guess, follow this everything you want to bet.
- In the Bank app you can press DEPOSIT to deposit all the money, withdraw to withdraw 10k, and DONATE to donate all the money from the bank
- In the business app you can buy business to increase the cash per second , money will be removed from the bank account.
